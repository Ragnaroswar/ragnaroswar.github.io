

# Eldoria
Jogo Eldoria: Criado inteiramente por Google Gemini 3.7 Flash
Prompt Inicial: "gere para mim um jogo text adventure em HTML5. Gere um código único contendo a estrutura completa."
Iterações e Correções: Apenas 2 iterações foram criadas. O jogo começou muito simples, e pedi para a IA criar mais escolhas e puzzles.
Desafios Técnicos: Na publicação, tive dificuldade em conseguir publicar o link do site rodando o jogo. Perguntei ao GitHub Copilot e ele me ajudou a publicar o Link.
